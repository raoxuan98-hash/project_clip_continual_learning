# 当前论文叙事

**状态**: 当前工作基线，随实验和理论核验更新  
**最后更新**: 2026-07-12

## 1. 中心问题

CLIP 的跨模态预训练使视觉表示既具备开放词汇语义，又支持图文检索。然而，类增量持续学习要求模型不断利用新类别监督信号改变表示。普通适配若沿历史任务已经高度响应的方向继续更新，容易同时造成历史类别干扰和预训练图文对齐退化。

本文研究的不是单独最大化增量分类精度，而是：如何让 CLIP 在持续获得新类别判别能力的同时，保持其原有跨模态检索能力。

## 2. 核心方法缺口

全文不应把现有方法简单概括为“没有使用零空间”，而应区分三个具体缺口：

1. **标准 LoRA** 将更新限制为低秩 (AB)，但低秩本身并不阻止适配器沿历史激活的高能量方向学习；
2. **传统零空间梯度投影** 通常在常规前向与反向之后修正梯度，没有把历史子空间结构持续嵌入 LoRA 的前向参数化；
3. **零空间启发的 LoRA 变体**利用低能量激活方向的基初始化或约束输入侧因子 (A)，但没有在两个可训练因子之前持续放置固定的历史激活滤波器。

这三者共同留下一个问题：能否把由历史激活谱构造的近似零空间滤波器直接嵌入 LoRA 支路，使适配器在整个训练期间都在过滤后的输入空间中学习？

## 3. 核心叙事

本文从训练参数化、跨模态表示约束和预测决策三个层次处理适应—保持矛盾：

1. **LoRA-NF** 是训练端主创新。它将标准 LoRA 的 (AB) 重参数化为 (PAB)，使 adapter 支路持续执行 (X\rightarrow XP\rightarrow XPA\rightarrow XPAB)；
2. (P) 由历史任务的输入激活 second-moment spectrum 构造，对历史高能量方向施加强抑制，对低能量近似零空间方向保留更大学习自由度；
3. 引言只说明泄漏式过滤在保留适配灵活性的同时，使学习偏离历史高能量方向；可逆条件、表达集合不变和谱相关优化几何作为方法正文的正式结论；
4. **跨模态知识蒸馏**从表示行为层面显式维持图文对齐，是跨模态检索保持的主要机制；LoRA-NF 的机制责任则限定为历史任务保持；
5. **LR-RGDA 与 CLIP 文本分类器集成**是重要的预测组件：LR-RGDA 从适配后的视觉空间建立类别条件分布判别，文本分支提供语言语义先验；引言只简要说明其互补性，和 LADA 的细致对比留到相关工作与实验。

最终希望证明：该框架在图文检索退化受控的同时，实现强竞争力、目标为 SOTA 级别的 CLIP 类增量持续学习性能。

## 4. 贡献层级

### 4.1 主贡献：LoRA-NF

- 形式：

\[
\Delta W=PAB.
\]

- 概念：persistent forward null-space filtering；
- 数据来源：历史任务层输入激活的 second-moment/Gram matrix；
- 机制区别：不同于 post-backward gradient projection，也不同于仅将近似零空间信息注入输入侧因子 (A) 的初始化或约束；
- 理论主线：历史响应干扰上界，以及可逆 (P) 下表达集合不变但优化几何改变；
- 实证主线：标准 LoRA、null-space-inspired (A) 变体、梯度投影与 LoRA-NF 的公平消融。

### 4.2 辅助训练机制：跨模态知识蒸馏

- 作用是显式维护图像—文本关系，是跨模态检索保持的主要机制；
- 不与 LoRA-NF 并列成两个同等重量的训练端主创新；
- 需要由 FD/CD 拆分消融以及分类—检索双指标说明贡献。

### 4.3 预测端贡献：集成分类器

- LR-RGDA 利用类别均值、正则化低秩协方差、全局协方差与多中心统计形成监督视觉判别分支；
- CLIP 文本分类器保留语言派生的类别语义先验，并为未由 LR-RGDA 建模的类别提供决策依据；
- 该集成是实现强持续分类性能的重要元素，但在全文贡献层级上从属于 LoRA-NF 主导的完整框架；
- 它只改变分类决策，不影响图文检索；与 LADA 的 prototype/memory affinity 对比放在相关工作和实验分析；
- 需要独立报告 CLIP-text、LR-RGDA 和 Ensemble，并在可比文本分支下与 LADA 的 visual-memory/text fusion 对照。

## 5. 实验必须回答的问题

- 完整方法是否达到或超过强 CLIP 持续学习基线；
- 持续学习后图文检索能力是否得到保持；
- LoRA-NF 是否在公平参数量和预算下优于标准 LoRA；
- LoRA-NF 的优势是否来自持续 (PAB) 参数化，而非初始化、额外参数或不同子空间维度；
- (P) 是否确实降低历史激活上的 adapter 响应、表示漂移或高能量方向更新；
- 跨模态蒸馏是否改善检索保持，并对分类形成辅助收益；
- LR-RGDA 与 CLIP 文本分支是否稳定互补，并在控制文本侧适配后优于 LADA 式标签记忆融合；
- 结论是否在多种子、明确任务顺序和统一协议下成立。

## 6. 当前边界

- “SOTA”在最终同协议主表完成前仍是目标性表述；
- LoRA-NF 直接服务于历史任务保持，不承担跨模态检索保持的机制主张；后者主要归因于跨模态知识蒸馏，并由检索实验验证；
- 当前实现默认使用 seen-tuned/unseen-frozen 的 LADA-style hybrid text classifier；在最终实验分支固定前，正文应使用“CLIP text classifier”，不能笼统称为“frozen zero-shot classifier”；
- 主配置中的 (P) 为泄漏式满秩滤波器，不能声称严格零空间投影或严格零干扰；
- 只有在 (P) 可逆时才能声称不缩减同 rank LoRA 的表达集合；
- AdamW 非等价性需要正式推导或受控实验，暂不表述为普遍性能保证；
- 所有正式数字必须追溯到最新 claim–evidence ledger 和原始结果。
