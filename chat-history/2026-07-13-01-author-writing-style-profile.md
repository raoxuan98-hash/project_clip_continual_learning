# 作者论文写作风格画像

**日期**: 2026-07-13  
**会话概况**: 基于作者自定义论文写作 skills 和 TPAMI 投稿论文，建立全项目可复用的论文风格画像。

---

## 1. 关键讨论 / 决策

- 实际论文样本的风格证据优先于通用写作模板。
- 作者偏好问题驱动、机制密集、证据约束的叙述，以瓶颈拆解推动方法模块出现。
- 公式采用“动机—定义—解释”顺序，理论采用 Lemma/Proposition/Remark 分层。
- 当前论文没有确定投稿 venue 或篇幅限制，应完整保留 TPAMI 式论证逻辑；只消除无意义重复，不做页数驱动的内容压缩。

## 2. 重要发现

- 作者的段落通常具有明确主题句、因果推进和连接下一段的收束句。
- Related Work 按技术类别组织；Experiments 偏好隔离组件贡献并解释机制。
- 需要避免机械复制 TPAMI 中较长句式、重复贡献宣称和过强形容词。

## 3. 待办事项 / 遗留问题

- [ ] 后续所有正式草稿使用该风格画像进行一致性检查。
- [ ] 在写入 LaTeX 前，对 Introduction、Related Work 和 Method 做一次风格校准。
