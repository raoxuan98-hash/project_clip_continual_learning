### 关键观察

1. **LoRA-NF 完整方法双种子 Ens 为 61.91 / 73.19 / 83.95**，与 LADA 复现值 61.90 / 73.17 / 83.90 几乎重合，稳定性好。
2. **Average 不是 Transfer 与 Last 的算术平均**：Average 是增量学习曲线在所有任务/所有时间步上的平均准确率；Transfer 仅看未见类零样本阶段，Last 仅看最终任务完成后的全类测试。因此 LoRA-NF 完整方法出现「T≈LADA、L 明显高、A 略高」是合理的——它在中间任务阶段积累了优势。
3. **LoRA-NF 无 CD 的 Transfer 更高（62.42）**，但 Average 低于完整方法（72.50 vs 73.19），说明 CD 对中间阶段 / Last 有正向作用。
4. **LoRA-only 仍有明显差距**，Average 仅 67.10，证明 NSP + CD 的组合对持续学习有效。
5. **检索能力**：LoRA-NF 在 Flickr30k i2t 上 81.30，较 LoRA-only（78.90）保留更好；t2i 上 LoRA-only 反而略高（63.02 vs 61.89），需进一步分析。
6. **SigLIP2 LoRA-NF**：Transfer 59.50、Average 68.66、Last 86.81；Last 优势明显，但 Transfer/Average 低于 CLIP LoRA-NF。MSCOCO i2t R@1 63.89、t2i R@1 46.91，跨模态检索显著强于 CLIP。
